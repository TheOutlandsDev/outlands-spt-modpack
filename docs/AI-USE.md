# AI use and provenance

This public package was prepared with Codex under the owner's instruction to publish an Outlands SPT developer/testing modpack while excluding game files and personal data. Existing original projects also use Codex names and metadata; no complete creation history was available to reconstruct their development process.

AI assistance in this release covered read-only installation inventory, license-document review, source selection, privacy sanitization, portable build/install scripts, documentation and validation. The current package number was assigned for this public export; it does not establish a historical 0.1.0 gameplay release.

`manifests/source-provenance.json` records original source-file hashes and hashes immediately after initial sanitization. Later explicitly documented hardening/build fixes may change package files; `SHA256SUMS` is authoritative for the final export. `manifests/mod-inventory.json` records installed component binary metadata/hashes. Third-party binaries are not attributed to Outlands. Unavailable source history and unperformed runtime tests are recorded as limitations.

No game/server was launched, no live build was installed, no profile state was intentionally changed and no third-party author was contacted during packaging. Publication was explicitly requested by the owner. No captured logs, private credentials, player identifiers or retail game files are intended for publication.
