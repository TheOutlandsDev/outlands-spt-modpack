# Outlands SPT Modpack 0.1.0-dev.1

Tag: `v0.1.0-dev.1-spt4.0.13`

First public developer export for **SPT 4.0.13 / EFT 0.16.9.40087**. Contains nine original projects with source and rebuilt DLLs; baseline original AI population/transit/diagnostics components; optional Scav Life, QuakeBrain and compatibility experiments; selected MIT third-party mods; and an optional Fika client 2.2.5.0 / server 2.0.9 layer with preserved notices and sanitized settings.

Includes the local component inventory, license decisions, documented customization summary, portable build tooling, verified backup/install tooling and SHA-256 manifests. The full original local build includes additional external mods that are not cleared for redistribution here. SPT runtime and retail game files are prerequisites, not release assets.

This is an independent **developer prerelease**, not an official SPT/Fika release and not a gameplay-validated modpack. See `docs/VERIFICATION.md` for checks actually completed and `docs/TEST-PLAN.md` for remaining runtime work. Use a separate test installation and a disposable profile.

Original code is MIT; bundled third-party files keep their own licenses. The Fika layer is CC BY-NC-SA 4.0 and noncommercial. No game files, profiles, certificates, original credentials or captured telemetry are included.
