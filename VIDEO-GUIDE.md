# Outlands video links and recording checklist

Use https://github.com/TheOutlandsDev/outlands-spt-modpack as the main video link.
Use https://discord.gg/cNqhhUdFW for access requests and community help.
Link the join and self-host guides so viewers can choose their intended path.

Before recording, hide connection profiles, live server/tailnet URLs, invites,
keys, launcher login data, personal names/emails, player profiles and raw logs.
Show the public README/installer and a redacted or demonstration dashboard.
Do not record the Tailscale admin page or a QR/invite/auth link.

State the exact public installer release and whether the footage comes from the
maintained hosted setup or an independent reconstruction. The current unmodified Client/SelfHost download matches the hosted static
baseline; four private host identity fields are supplied independently. A source build, idle Ready screen or file audit is not
a completed co-op test. Record a shared Ground Zero raid, extraction/save results
and a subsequent raid before describing that exact package as playtested.

Viewers need a legitimate compatible EFT/SPT installation. Downloading the public
bootstrap does not approve hosted access. Do not ask viewers to post private
connection or device information in YouTube comments or public GitHub issues.
