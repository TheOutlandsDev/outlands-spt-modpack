# Outlands SPT Modpack Branding

Small SPT server compatibility mod that changes cosmetic branding labels to:

- `Outlands SPT Modpack`
- `v0.1.0-dev.1 / SPT 4.0.13`

It leaves `compatibleTarkovVersion` untouched so client version validation still uses the real EFT build.


Public package note: installation paths in legacy examples are placeholders. Use the central build/install scripts described in the root README. Headless setup scripts are manual tools; they are not run by the package installer.
